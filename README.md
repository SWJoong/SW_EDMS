## 🏢 프로젝트 소개

**바이브코딩으로 쉽게 만들 수 있는 것들**

이 내용을 읽고 계신다면 아마 강의 전에 제가 과제로 여러분께 드렸다는 것이겠죠?
과제 전에 가벼운 잡답이라고 생각하시고 편하게 읽어주세요~

2026년 7월 말을 기준으로 Antigravity로 제작한 전자결재 시스템을 보여드릴 예정입니다.  
이 샘플은 아주아주 간단하게, 바이브코딩을 아예 시도해본 적이 없어서  
어떻게 시작해야 할지 모르겠는 분들도 따라할 수 있게 만들었습니다.  
프롬프트는 딱 한 번만 입력해서 만든 초안입니다.  
인공지능 모델을 **gemini flash 3.6 high**로 설정하고 돌렸습니다. 5시간 토큰 제한 기준 12% 정도만 썼는데요.  
아주 빠르고 그럴싸하게 제작해주더랍니다. 샘플 데이터부터 작동 로직까지 당장 쓰기엔 큰 무리가 없어보일 정도였습니다.  

대신 사람이란 게 욕심이 들다 보니 이것도, 저것도 추가하고 싶어지겠지요?
샘플 사이트를 자세히 보시면 글자도 정렬이 되어 있지 않고, 뭔가 우리 기관 내용이랑은 완전 대응이 안되는 것도 같고...  
아 불편해~~ 하면서 수정을 요청하다 보면 어느새 토큰은 다 써버렸고...  
겨우 모양새는 다 잡았는데 저장한 데이터는 어디서 본담? 저장은 왜 안 돼? 하고 보면 뭘 또 연결해야 한다네요.  
그렇게 만든 우리 기관의 바이브코딩 앱. 뿌듯한 마음으로 직원들에게 보여줬는데 아무 반응도 없거나, 내가 테스트할 땐 없던 오류가!  
다시 자리로 돌아가 수정하기 시작.  
......

어느덧 내가 만든 앱 하나가 완전히 자리를 잡아 직원들이 잘 활용한다면요?  
아이디어도 샘이 솟아 우리 기관에 필요하다고 느꼈던 수많은 프로그램이 생각나기 시작할 겁니다.  
그러다 보면 처음엔 놓쳤던, 우리가 만들면서 신경써야 할 것들이 눈에 밟힙니다.   
배포, 보안, DB 관리, 인공지능 추가 시 발생하는 API 비용, 도메인 유지 비용, 사용자 테스트와 오류 수정 등.  
바이브코딩으로 무언갈 만들다 보니 '아, 괜히 전공자가 있는 게 아니구나'를 느낍니다.  
세세하게 파고 들어가다 보면 충분한 지식과 시간, 자원이 필요하다는 걸 알게 되었습니다.  

그래서 이런 생각도 들었습니다.  
'개발자도 아니면서 이런 걸 이만큼 공부하는 게 의미가 있을까?'  
'사회복지사인 나는 사회복지 현장의 전문가로서 어떤 전문성을 발휘하고 있는가?'  
개인과 사회의 균형을 이룰 수 있도록 돕는, 관계 맺기 전문가로서, 사회사업가로서  
일할 때 정말 바이브코딩이 도움이 되고 있는지, 본말전도인 건 아닌지 고민하게 되더라고요.  
아직은 잘 모르겠습니다. 사회복지 전문가가 되기 위해 경력과 노력이 더 필요할 것 같아요. ^--^&  

그래서 저는 이렇게 목표를 세웠습니다. 아주아주 기본적인 것, 내가 바꿀 수 있음직한 것부터 바꿔보는 겁니다.   
종이에 날인 찍어서 근태관리를 해왔다면, 바이브코딩으로 이런 행정업무 시스템을 만들어 직원들에게 공유해보는 겁니다.  

그렇게 아까 이야기한 여러 실패를 거치다 보면 마음이 다시 꺾이기도 하고 평가 준비 때문에,  
기관 행사 준비 때문에 다시 시간이 부족해져 바이브코딩 공부하고 만들 짬이 안 날지도요.  

그래도 뭔가 불편하긴 하지만 이 시스템을 쓰게 되면서 손으로 쓰고 지우고 하던 시간에  
당사자의 장애 정보에 대해서 조금이나마 공부할 짬이 나고,  
그 시간이 당사자를 이해하는 데 조금이나마 도움이 되었다면 우리가 바이브코딩을 공부하고  
시도한 게 그 순간만큼은 헛되거나 본말전도된 게 아니라고 생각해보는 중입니다. ^^  
아래 내용을 쭉 살펴 보시면서 어떤 방식으로 대화를 나눠야 하고 내가 무엇을 알고 있어야 하는지 감을 익혀보세요.  
파일을 가져다가 따라할 수 있는 방법도 맨 아래에 적혀 있습니다~

## 🤖 Antigravity AI 프롬프트 기반 앱 제작 가이드

본 시스템은 **Antigravity AI 에이전트**와 대화하며 단계적으로 구축되었습니다. 에이전트를 효율적으로 활용하는 프롬프트 작성 노하우를 소개합니다.

### 🎯 Step 1: `/goal` 프롬프트로 기초 골격 및 MVP 요구사항 정의

> 첫 번째 단계에서는 **도메인 특성, 사용자 수, 수직적 조직 구조, 필수 결재 서류 7종, 날인 첨부 요구사항, 기술 스택 및 배포 계획**을 명확히 정의하여 프로젝트 전체 아키텍처와 기본 UI/UX를 구축합니다.

#### 💬 입력한 프롬프트 (Prompt #1):
```text
/goal 사회복지기관에서 사용할 E-HR 형식의 전자결재 시스템을 제작할 예정입니다. 기관 규모는 최대 5~50명 사이로 잡습니다. 최고 결정권자(센터장, 관장 등), 중간 관리자(사무국장, 과장, 팀장, 주임 등), 실무자(사회복지사) 형식의 수직적 조직문화를 기반으로 하며, OU를 설정할 수 있어야 합니다.
날인 이미지가 문서 내에 첨부 가능해야 합니다.
구현하고자 하는 전자결재 행정 서류는 다음과 같습니다.

1. 연차사용
2. 공가, 병가 등의 특수한 상황에서의 휴가 관리를 위한 '근무상황부2'
3. 출장신청
4. 시간외근무명령
5. 시간외근무확인
6. 교육신청
7. 교육 결과보고

MVP를 제작 후 kakao map api 연동, firebase 또는 supabase DB 연결, vercel 또는 netlify로 배포할 예정입니다.
코드 관리는 github로 할 예정입니다. Implement plan 수립을 진행하고 phase 별 어떤 task 진행 예정인지 안내해주세요.
```

##### 💡 Step 1 프롬프트의 핵심 포인트:
- `/goal` 명령어를 통해 에이전트가 장기 목표를 파악하고 전체 아키텍처 플랜(Implementation Plan)을 수립하도록 유도합니다.
- 조직의 명확한 페르소나 및 요구 서류 목록(7종)을 명시하여 데이터 구조 설계 시 누락이 없도록 합니다.

### 🚀 Step 2: 추가 프롬프트로 세부 확장 기능 구현

> 두 번째 단계에서는 MVP 골격이 완성된 후, **실무 편의성을 높이는 연동 기능(캘린더, 자원 예약, 맵 기반 여비 품의, 근태 관리)**을 구체적으로 요청하여 시스템을 고도화합니다.

#### 💬 입력한 프롬프트 (Prompt #2):
```text
이번 구현을 통해서 더 추가하고 싶은 기능이 몇 가지 더 생겼습니다.
1. 구글 캘린더 연동 및 현재 시스템 내에서 각 직원별 근무현황 시각화
2. 각 담당자별 일정에 따른 회의 일정 등 소규모&대규모 미팅 등 예약 시스템(노트북, 회의실 등의 자원 반영 시 예약 제도 생성)
3. 카카오맵 API 등을 활용한 출장 명세(출장지까지의 여비 품의 및 증빙)
4. 근태관리 내역(지각 등의 근태 사항 기록)
```

##### 💡 Step 2 프롬프트의 핵심 포인트:
- 기존에 작성된 코드를 유지하면서 추가 모듈(Google Calendar UI, Resource Booking, Kakao Map, Attendance Log) 형태로 자연스럽게 연동되도록 조립합니다.

## ✨ 주요 기능 (Features)

### 📄 1. 전자결재 서류 7종 제공
- **연차사용신청서**: 반차/연차 자동 계산 및 잔여 연차 연동
- **근무상황부2**: 공가, 병가, 경조사 등 특수 휴가 사유 작성 및 증빙 첨부
- **출장신청서**: 카카오맵 기반 출장지 검색, 여비 품의 자동 계산
- **시간외근무명령서**: 사전 시간외 근무 신청 및 승인 프로세스
- **시간외근무확인서**: 실제 근무 시간 검증 및 실적 등록
- **교육신청서**: 직무 교육 신청 및 관련 예산 신청
- **교육결과보고서**: 교육 이수 후 결과 및 소감 보고서 작성

### 🖋️ 2. 전자 날인/도장 서명 기능
- 사용자별 도장/서명 이미지 등록 및 결재 완료 시 결재란에 실시간 반영

### 🏢 3. 수직적 조직도 (OU) & 결재선 지정
- 센터장 / 사무국장 / 팀장 / 사회복지사 등 조직도 계층 트리 조회 및 자동 결재선 지정

### 📅 4. 근무현황 시각화 & 구글 캘린더 연동
- 전체 직원의 출장, 휴가, 시간외 근무 일정을 타임라인/캘린더 뷰로 시각화

### 💻 5. 자원 및 미팅 예약 시스템
- 회의실, 노트북, 기관 차량 등 공용 자원 예약 및 미팅 일정 관리

### 🗺️ 6. 카카오맵 연동 출장 여비 품의
- 출발지/목적지 검색을 통한 경로 및 이동거리 산출, 여비 산정 기능

## 🚀 시작하기 (Getting Started)

### 사전 준비 사항
- Node.js (v18 이상 권장)
- npm 또는 yarn

### 설치 및 실행

1. 저장소 클론 (Clone repository)
   ```bash
   git clone https://github.com/SWJoong/SW_EDMS.git
   cd SW_EDMS
   ```

2. 패키지 설치 (Install dependencies)
   ```bash
   npm install
   ```

3. 개발 서버 실행 (Run development server)
   ```bash
   npm run dev
   ```

4. 브라우저 접속
   - `http://localhost:5173` 접속하여 앱 확인
